# TRAJECT

> **Explainable Narrative Intelligence Platform**  
> Moving from prototype to production architecture.

## Overview

TRAJECT transforms multi-platform social streams into explainable narrative intelligence—modeling information cascades, tracking narrative genesis, detecting framing mutations, and identifying network bridge dynamics.
